# UI Lab languages

The page header switches between 中文 and English. UI Lab defaults to Chinese and remembers its own preference in `UI_LAB_LOCALE_STORAGE_KEY`; it does not change the product locale setting. Restricted local storage does not prevent switching. The provider updates the document language and does not remount the active panel or clear its hash, selections or edited text.

Copy uses the existing `createTranslator` mechanism with matching `messages.zh.uiLab` and `messages.en.uiLab` catalogs in `shared/i18n/uiLab.ts`. `labMessageKeys` maps authoring source strings to stable catalog IDs; `useLabTranslation().text` resolves them. Add both languages and a source mapping for new UI copy. IDs must stay stable. Dynamic values, token names, URLs and user edits are passed separately, not translated by changing the DOM or source data. Labels from module-level option arrays are translated at render time while option values remain stable. Search matches original bilingual names and the current language.

The scope includes navigation, the seven component introductions, all foundation notes, state labels, playground controls, validation feedback, accessible names, and the existing dialog/selection examples. Business component demos receive the selected locale through their existing translator props. Static Figma reference glyphs, text, variable paths, token names and preset identifiers remain original for design comparison; the page explains this exception. Editable toggle and checkbox defaults follow the locale until edited, then retain exactly the user's input.

Verification: UI Lab integration tests cover switching both ways, translated descriptions/status/navigation, Chinese search in English mode, edited label and switch-state retention, hash preservation, independent preference storage, and preference restoration. Catalog parity is checked. Browser verification in IAB at default zoom: LAY-01 and TXT-02 pass at1149×841,768×900 and390×844 for readable preferences, wrapped English copy and no page-wide overflow; LOC-02 and FORM-03 pass for switching both ways, edited text/switch retention, and newly opened English/Chinese dialogs. English remains selected after reload, and the original hash remains intact. Catalog metadata and static Figma samples intentionally retain original source language. Other product routes are outside the UI Lab verification scope.
