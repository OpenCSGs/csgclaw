# 模型接入与切换

模型设置按厂商品牌分组，并区分普通 API、Coding Plan、Agent Plan 和 Token Plan。
选择服务和区域，通过“获取 Key”进入官方控制台，填入 Key 后点击“连接”。
地址和协议自动匹配；自定义名称、地址、协议、请求头和模型 ID 放在高级设置中。
同一服务支持多个账号，重名连接自动添加序号。

## 支持的服务

支持 OpenAI API、Claude API、Kimi API 与 Coding、百炼 API 与 Token Plan、火山方舟 API 与 Coding Plan、Agent Plan、GLM API 与 Coding Plan、MiMo API 与 Token Plan、MiniMax API 与 M Plan，以及 DeepSeek API。
国内厂商默认选择国内区域，提供官方支持的国际平台或海外集群。
MiMo Token Plan 可选中国、新加坡和欧洲，百炼可选国内平台和国际版新加坡区域。
每种服务的官方文档、Key 入口、地址和协议统一维护在 `internal/modelpreset/catalog.go`，通过 `GET /api/v1/model-provider-presets` 提供给前端。

Claude API 使用官方控制台 API Key，通过原生 Messages 协议接入，与 Claude Code 账号登录入口分开。
API Key 与套餐 Key 必须匹配所选服务及区域，即使地址相同也不能混用。
套餐及模型权限以厂商条款和账号权益为准。
连接失败不会自动更换区域、计费通道，也不会伪装成其他客户端绕过权限限制。

## 连接验证与配置

创建接口支持 `preset`、`region`、`api_protocol` 和 `connect: true`。
连接模式下，后端获取模型；存在对话模型时验证最小推理请求，成功后才保存配置。
仅提供图片或视频模型的服务通过带认证的模型目录验证，检测连接不会创建付费的图片或视频生成任务。
`api_protocol` 支持 `responses`、`chat_completions` 和 `anthropic_messages`，在配置加载、保存、onboard、Agent 和会话配置解析中保持一致。
运行时仍调用本地 LLM 桥接层，由桥接层转换上游协议、流式事件及工具调用。

模型列表优先通过厂商接口获取。
接口不支持模型发现或返回空列表时，使用官方文档预设或手动指定的模型，并通过最小推理验证后才显示连接成功。
列表来源标记为 `upstream`、`preset` 或 `manual`。
预设列表是官方文档中的候选模型，实际权限以账号为准。
Key 无效、权限不足、余额或套餐额度不足、限流、网络异常分别提示。
失败连接不会因为存在预设列表而变为成功状态。

Key 由后端持久化，连接目录与错误消息保持脱敏。
官方 Logo 随应用本地打包，来源记录在 `web/app/public/model-providers/SOURCES.md`。

## 新建 Agent 的模型选择

设置中不再提供独立的“默认模型”表单。
Agent 成功创建后，后端记住本次选择的对话、图片生成和视频生成模型，供下一次创建使用，刷新浏览器或重启服务后仍保留。
修改已有 Agent、取消创建或创建失败不会改写这份记录。
新建时按类别检查上次选择是否仍可用，失效或缺失时优先选择同一服务的可用模型，再选择其他可用服务。
失败的服务不会作为默认项；没有可用模型的类别留空。
自定义创建和 Agent 设置共用图片、视频模型选择控件。

## 更换模型

Agent 设置决定新会话的默认模型。
聊天中更换模型仅影响当前会话，保留记录，从下一次发送起生效。
“跟随 Agent 默认模型”可移除会话覆盖配置。
回复过程中禁用切换，保存失败保留原选择，刷新后恢复已保存的选择。
Agent 配置和聊天使用同一个可搜索选择器，显示服务与连接名称，避免混淆同名模型。

## 验证范围

协议契约测试覆盖预设、区域、认证、模型发现、失败连接、配置持久化以及三种协议的工具调用与流式回复。
无头界面验证覆盖接入、失败重试、模型选择、会话切换与刷新、键盘、深浅主题、窄屏和子路径部署。
没有真实测试 Key 的厂商使用协议夹具验证，不能据此声称已完成该厂商的真实连接测试。
