## What's Changed

This release adds DeepSeek Harness workers, shared connectors, and video generation, with clearer execution progress and diagnostics and more reliable resource and conversation handling.

### Features & Improvements

- **DeepSeek Harness workers**: Create DSH workers with managed installation, built-in templates, and a selectable workspace. Installation defaults to DSH `0.1.5-rc.3`; workspace write is the default permission mode, with read-only and full-access options.
- DSH workers can use Agent connectors and managed `lark-cli` tools for Feishu, preserving extension state across updates and recreation.
- Publish DSH workers and local templates to the community and create Agents from shared templates with their runtime selection preserved.
- **Shared connectors**: Reuse named GitLab and Feishu connections across Codex and DSH Agents with isolated sessions. Supports GitLab PATs, independent Feishu credentials with automatic token refresh, and current OpenCSG login for supported endpoints.
- Manage application and MCP connectors together, view live connection states, and automatically reconnect interrupted HTTP MCP sessions without repeating failed tool calls.
- Connector setup now lives in Resources and Agent profiles, replacing the old chat-composer controls. Adding new llm-wiki connectors is temporarily unavailable in the UI.
- **Video generation**: Use a separate video model in writable Codex Web UI chats with an AIGateway-compatible async provider. View progress and previews, resume known jobs after restart, and retry failed delivery.
- **Readable chat progress**: Stream explanations and tool activity with expandable command details, context usage, and Stop controls. Progress survives history refreshes and reconnects.
- **Performance diagnostics**: Inspect message and Agent execution timings, rankings, timelines, commands, and errors. More detailed Codex execution data is shown when available; unmeasured model timings are clearly marked.
- Feishu adds native progress display, streamed replies, permission/question cards, cancellation, and bounded retries for failed final replies. Pending deliveries are not recovered after restart.
- Added GPT-6 Sol, GPT-6 Luna, GPT-6.1 Sol, Claude Opus 5.5, and Claude Sonnet 5.5 to authenticated provider model choices.
- Configure model context limits and view live usage in Codex and DSH. Both support compaction recovery at a 75% threshold; DSH also allows automatic compaction to be disabled.
- Enable or disable installed Skills and MCP servers in Codex and DSH profiles without deleting them. Running Agents reload changes; stopped Agents apply them on next start.
- Profile resource lists and chat Skill pickers load more results on scroll, with loading retries. Disabled Skills are excluded from chat suggestions.
- Upload up to 10 attachments per message: **1 GiB per file, 2 GiB total**. Files remain accessible across turns, with native audio/video playback.
- Delete room attachments through the Web UI, CLI, or API, with immediate chat updates and separately saved workspace copies preserved.
- Click inline document citations to inspect evidence snippets in a resizable source panel.
- The anonymous Agent chat API accepts supplemental text or web-page context: 64 KiB for text, 512 KiB for DOM input, and 128 KiB after sanitization.
- Submit feedback from Settings using the active OpenCSG login, with up to six JPEG/PNG screenshots of 5 MiB each. Failed submissions retain the form; GitHub feedback remains available.
- Added MSIX packages for Windows Store submission, supporting Windows 10 1809 or later. Store submission remains manual.
- Windows diagnostics include DSH logs, processes, network connections, and system events in one ZIP, collecting available data even when the app or API is unavailable.

### Bug Fixes

- Fixed ordinary restarts overwriting Codex host Skill copies and deleted built-in Skills reappearing. Updates preserve Skill choices and edits; recreation preserves custom Skills.
- Instruction saves now reload the runtime, even for unchanged content, and can retry failed reloads. Stopped Agents stay stopped; Recreate is removed from profile menus.
- Changing a Codex provider, endpoint, or model now starts a fresh runtime session, preserving visible chat history.
- Fixed Codex and Claude checks showing usable models without valid authentication. Failed checks clear stale catalogs and show actionable errors.
- Fixed stale model selections when creating Agents after switching OpenCSG environments, while preserving existing Agents' model configurations.
- Fixed Agent creation failures with certain Responses providers. Connection checks now finish without waiting for the complete reply.
- Knowledge-base requests and template checks now use the current identity, retain authorized LLM-Wiki resources, and keep user tokens out of persisted snapshots.
- Fixed private Skill search and installation missing matching Hub credentials, and hid replacement actions for protected built-in Skills.
- Remote MCP installation now validates access before saving, with a five-second deadline and retryable errors. Templates skip inaccessible resources with warnings; Agent pages load the catalog on first entry.
- Fixed MCP names containing Chinese characters or spaces, and preserved Agent bindings when renaming servers.
- Fixed interrupted state saves damaging the conversation index. Missing state files now leave remaining conversations intact and show recovery guidance.
- Fixed proxy and portal access being incorrectly blocked, including OpenCSG login and template chats. Authentication and Agent access checks remain in place.
- Fixed garbled previews for common Chinese, Japanese, Korean, and Western text encodings, preserving original download bytes.

## 更新内容

本次发布新增 DeepSeek Harness Worker、共享连接器和视频生成，并让执行进度与诊断更清晰，改善资源管理和会话处理的可靠性。

### 功能与优化

- **DeepSeek Harness Worker**：支持托管安装、内置模板及自选工作目录。默认安装 DSH `0.1.5-rc.3`，默认允许修改工作区，也可选择只读或完全权限。
- DSH Worker 可使用 Agent 连接器和托管的 `lark-cli` 飞书工具，更新或重建后保留扩展状态。
- 支持将 DSH Worker 和本地模板发布到社区，并从共享模板创建 Agent，保留运行时选择。
- **共享连接器**：多个 Codex、DSH Agent 可复用具名 GitLab、飞书连接，并使用独立会话。支持 GitLab PAT、飞书独立凭证与令牌自动刷新；适用服务可使用当前 OpenCSG 登录。
- 集中管理应用与 MCP 连接器，查看实时连接状态；HTTP MCP 连接中断后自动重连，不重复执行失败的工具调用。
- 连接器设置统一到资源页和 Agent 资料页，替代聊天输入区旧入口；界面暂不提供新增 llm-wiki 连接器的入口。
- **视频生成**：为可写模式的 Codex Web UI 会话配置独立视频模型，接入 AIGateway 兼容异步服务。可查看进度与成片预览，重启后继续已知任务，投递失败可重试。
- **清晰的聊天进度**：流式展示说明与工具活动，支持展开命令详情、查看上下文用量和停止执行，刷新历史或重连后保留进度。
- **性能诊断**：查看消息与 Agent 执行的耗时、排行、时间线、命令及错误。可用时展示更详细的 Codex 执行信息，未测量的模型耗时明确标示。
- 飞书新增原生进度展示、流式回复、权限与问题卡片、任务取消，以及最终回复失败后的有限重试。待投递消息不会在重启后恢复。
- 已认证提供方的模型选项新增 GPT-6 Sol、GPT-6 Luna、GPT-6.1 Sol、Claude Opus 5.5 和 Claude Sonnet 5.5。
- 可配置模型上下文容量，并查看 Codex、DSH 实时用量。两者均支持 75% 阈值的压缩与溢出恢复，DSH 还可关闭自动压缩。
- 可在 Codex、DSH 资料页启用或禁用已安装的 Skill 和 MCP，保留资源。运行中的 Agent 重新加载，已停止的 Agent 下次启动时应用。
- 资料页资源列表和聊天技能选择器随滚动加载，加载失败可重试；禁用的 Skill 不再出现在聊天候选中。
- 单条消息最多上传 10 个附件：**单文件 1 GiB、合计 2 GiB**。附件可跨轮次访问，音视频支持原生播放。
- 可通过 Web UI、CLI 或 API 删除房间附件，即时更新聊天，并保留另行保存的工作区副本。
- 点击行内文档引用，可在可调整宽度的来源面板中查看证据片段。
- 匿名 Agent 聊天 API 可附带文本或网页上下文：文本上限 64 KiB，DOM 输入上限 512 KiB，清理后上限 128 KiB。
- 可在设置页通过当前 OpenCSG 登录提交反馈，附带最多六张 JPEG/PNG 截图，每张不超过 5 MiB。失败时保留表单，GitHub 反馈入口继续可用。
- 新增可提交 Windows Store 的 MSIX 安装包，最低支持 Windows 10 1809；提交商店仍需手动操作。
- Windows 诊断将 DSH 日志、进程、网络与系统事件汇总为一个 ZIP，应用或 API 不可用时仍收集可获取的信息。

### Bug 修复

- 修复普通重启覆盖 Codex 宿主技能副本、已删除内置技能重新出现的问题。更新保留技能选择与修改，重建保留自定义技能。
- 保存指令即重新加载运行时，内容未变也可重试失败的加载。已停止的 Agent 保持停止，资料页移除「重建」。
- Codex 切换提供方、服务地址或模型后启动新的运行会话，保留可见聊天记录。
- 修复 Codex、Claude 未有效认证便显示模型可用的问题，检查失败时清除过期目录并提示处理方法。
- 修复切换 OpenCSG 环境后新建 Agent 沿用旧模型选择的问题，保留已有 Agent 的模型配置。
- 修复部分 Responses 服务导致 Agent 创建失败的问题，连接检查无需等待完整回复。
- 知识库请求和模板检查改用当前身份，保留有权访问的 LLM-Wiki 资源，并避免持久化用户令牌。
- 修复私有 Skill 搜索与安装缺少对应 Hub 凭证的问题，并隐藏受保护内置技能的替换操作。
- 远端 MCP 安装前校验访问权限，限时五秒，失败可重试。模板跳过不可访问资源并提示，Agent 页面首次打开即加载目录。
- 修复中文或带空格的 MCP 名称无法使用的问题，改名后保留 Agent 绑定。
- 修复状态保存中断损坏会话索引的问题；状态文件缺失时保留剩余会话数据，并给出恢复指引。
- 修复代理和门户访问被误拦截的问题，包括 OpenCSG 登录和模板聊天；保留身份认证与 Agent 访问检查。
- 修复常见中文、日文、韩文及西文编码的文本预览乱码，保留下载文件的原始字节。
