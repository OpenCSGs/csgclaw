## 本周发布更新

本周发布打通了社区模板发布与部署流程，增强 Agent 流式接口，并提升 Codex、Web、桌面端及运行环境的可靠性。

### 更新内容

- 社区模板现在支持从发布到部署的完整流程，包括私有部署、命名空间链接及更严格的校验和生命周期处理。
- 现在内置匹配版本的 Codex CLI，并增强下载、升级和配置变更后的重启流程，减少手动安装和维护成本。
- Codex Agent 的活跃任务不再受 30 分钟限制，长时间运行的任务可以持续执行。
- Agent API 新增 Anthropic 格式的流式响应，并改进对流式 Responses API 和 Chat Completions 的模型服务校验。
- Web 端优化附件预览和操作反馈，支持云端 Sandbox 资源路径，并在不支持下载时给出更明确的处理。
- 桌面端改进安装包发布、Windows 打包与诊断、主题同步和关闭期间重新打开应用的稳定性。
- Docker 检查改为延后执行，同时完善 CSGHub Lite 服务发现和飞书 Agent 绑定，减少启动及集成异常。

### 涉及版本

- [`v0.4.6`](https://github.com/OpenCSGs/csgclaw/releases/tag/v0.4.6)：新增社区模板发布与部署、Anthropic 格式流式响应和内置 Codex CLI，并集中改善 Web、桌面端、Sandbox、模型服务及外部集成的可靠性。

## Weekly Release Update

This week’s release completes the community template publishing and deployment workflow, expands agent streaming APIs, and improves reliability across Codex, the web app, desktop, and runtime environments.

### What's Changed

- Community templates now support an end-to-end publishing and deployment workflow, including private deployments, namespaced links, stronger validation, and safer lifecycle handling.
- The matching Codex CLI is now bundled, with improved downloads, upgrades, and restarts after configuration changes to reduce manual setup and maintenance.
- Active Codex agent turns can now continue beyond 30 minutes, allowing long-running tasks to finish without an artificial timeout.
- The agent API now streams responses in Anthropic format, while model-provider checks better support streaming Responses API and Chat Completions requests.
- The web app improves attachment previews and feedback, loads assets correctly from cloud sandbox paths, and handles unsupported downloads more clearly.
- Desktop reliability is stronger with improved installer distribution, Windows packaging and diagnostics, native theme synchronization, and safer reopening during shutdown.
- Docker checks are now deferred, while CSGHub Lite discovery and Feishu agent bindings are more reliable, reducing startup and integration failures.

### Covered releases

- [`v0.4.6`](https://github.com/OpenCSGs/csgclaw/releases/tag/v0.4.6): Added community template publishing and deployment, Anthropic-format streaming, and a bundled Codex CLI, with broader reliability improvements across the web app, desktop, sandbox, model providers, and integrations.
