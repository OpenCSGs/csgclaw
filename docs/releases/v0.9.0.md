## What's Changed

This release brings tasks, conversations, and Agent management into one workspace, adds in-chat resource selection and DSH persistent memory, and improves model setup, desktop browsing, and runtime reliability.

### Features & Improvements

- **Unified task workspace**: Start tasks with a selected Agent or team, manage Agents and teams alongside conversations, and search, pin, rename, archive, or restore conversation history.
- Create custom Agents through a five-step wizard with optional instructions, Skills, connectors, and knowledge bases. Template-based creation remains available, and teams now support editable descriptions.
- Configure the model, reasoning level, and starting working directory independently for each host Codex or DSH conversation, retaining native history across session setting changes and restarts. The working directory is fixed once the task is created; team and sandbox conversations retain their existing execution settings.
- Manage collaboration-room members, invitations, and external-message sources in a dedicated panel. Inspect room tasks and child progress, with an explicit **Ended with issues** marker for unresolved outcomes.
- **Choose resources in chat**: Select Skills, connectors, and knowledge bases in Codex and DSH direct chats, threads, floating chats, and new tasks. Search from the composer or use slash selection; selected resources remain visible in message history and are checked for availability when used.
- Add Skills directly from an Agent's profile: select from the global library, upload a ZIP, or browse market files before installing. Market installs and updates update the global copy and enable it for the selected Agent.
- Add connectors from the Agent profile, using configured App resources or selecting, manually configuring, and installing MCP servers from the market.
- Use a dedicated Knowledge bases tab to enable connected resources or connect accessible AgenticHub knowledge bases without leaving the Agent profile.
- **DSH persistent memory**: DSH Agents gain an Agent-scoped summary, searchable handbook, immediate memory tools, and background extraction from ordinary chats. Memory is enabled by default and survives restarts and rebuilds; background extraction starts after a 61-minute waiting window rather than immediately. Templates include the summary only when explicitly selected.
- Codex and DSH share managed CLI connector packages and their Skills. Existing Feishu installations migrate to the shared flow, compatible image-preinstalled packages can be imported offline, and authorization shows separate bot and personal-account stages with cancellation and recovery controls.
- Connector lists display saved resources immediately and refresh health independently in the background, so slow discovery does not block other resources. Connection details expose tools, configuration, and cleanup retry guidance.
- Set up models using provider and API/Plan presets, regional endpoints, official Key links, and connection verification. Advanced settings support custom endpoints, headers, model IDs, and Responses, Chat Completions, or native Messages protocols; credentials must match the selected service and region.
- New Agents prefer connected OpenCSG `auto` and available OpenCSG image/video models, with other connected providers as fallbacks. Explicit defaults, including **Unspecified**, persist; creation requires a conversation-model choice when no default is specified.
- Restore context limits for an individual model or an entire provider, applying changes through Save.
- **Per-turn token usage**: View input/output totals, available cache and reasoning details, and the selected model below replies. Codex and DSH aggregate calls within each turn, retain statistics in history, and distinguish partial or unavailable usage; `auto` hides the model name.
- Use shared chat tool tabs for files, previews, websites, activity, threads, and sources, with searchable files, clearer format icons, and workspace breadcrumbs.
- **Native desktop browsing**: Open websites in a Chromium panel with navigation controls and a persistent browser profile separate from the app login, including sites that refuse iframe embedding. This requires an updated Desktop build; the Web edition retains iframe browsing with external opening as a fallback.
- Open local workspace files and directories in a file manager, editor, or terminal, and choose suggested applications for generated attachments. Remote access retains bounded paths and appropriate fallbacks.
- Navigate long conversations with a message timeline, prompt/reply previews, and click, drag, wheel, or keyboard controls.
- Agent logs use local timestamps, and reply diagnostics focus the selected turn and include selected-model and redacted upstream failure details.
- Templates support Chinese display names and preserved Agent avatars, with clearer Official, Mine, and public grouping. Save a local snapshot before publication, replace existing local snapshots when retrying, and continue cloud Agent creation and management in AgenticHub.
- A built-in CSGClaw self-diagnosis Skill guides Agents to inspect runtime evidence and version-matched source for Desktop, server, sandbox, and integration problems.
- Successful turns trigger deduplicated desktop notifications with persistent sound controls and concise plain-text previews.
- Operators can set the Codex execution policy through `CSGCLAW_EXECUTION_MODE=standard|read_only`. The default is `standard`; invalid values prevent startup, and session settings cannot relax a server read-only policy.
- Conversation persistence skips rewriting unchanged data while retaining synchronous atomic saves for changes, reducing unnecessary disk writes.

### Bug Fixes

- Fixed Codex workers stopping after client disconnects or failed/timed-out turn interruption. Unconfirmed cancellation is reported while the worker remains available for follow-up requests.
- Fixed desktop startup timing out during slow connector restoration and fresh installations starting Manager before HTTP/MCP was ready. Saving the first complete model configuration now starts Agents intended to run; explicitly stopped Agents remain stopped.
- Fixed Windows profile changes failing to restart Agents after an exited process was cleaned up again. Configured offline Codex Agents can recover before chat, and **Needs rebuild** offers a confirmation flow.
- Fixed DSH reasoning choices unsupported by the runtime preventing conversations from starting or resuming. Fallback uses supported common levels without silently promoting `xhigh` to runtime-specific `max`, preserving the saved choice.
- Fixed the LLM bridge expanding requested output-token limits for Qwen and other compatible services. Chat Completions and Responses fallback preserve caller-supplied limits for the model service to validate.
- Fixed CSGHub template-worker creation depending on an immediate online model probe. Template creation still validates runtime options and resources, while model errors surface during chat; the creation dialog refreshes templates before selecting defaults.
- Fixed new Agent creation mixing models from different providers or unexpectedly falling back to local Lite. Custom instructions and the selected Skill set are preserved through creation.
- Fixed connector health depending on Agent binding failures, stale errors remaining after successful checks or canceled authorization, and custom OpenCSG login sites not being recognized.
- Fixed Skill source information being lost across restarts and workspace rebuilds, and knowledge-base metadata being lost after disable/re-enable. Resource retries retain installed results, and updating a market Skill preserves unrelated Agent Skills.
- Fixed template ownership, publication status, and navigation becoming stale, including newly published templates missing from refreshed lists. Publication excludes local Skill process locks, and deletion clearly identifies its local-only scope.
- Fixed long conversation histories delaying typing, new-task replies failing to appear live, and automatic scrolling hiding replies behind the composer. Reading older messages preserves the scroll position and offers a **View latest** action for new replies.
- Fixed task cancellation losing its Stop action after participant updates, canceled tasks appearing as runtime failures, worker exits leaving pending turns unresolved, and room dispatch or claim results depending on notification congestion.
- Fixed HTML, PDF, spreadsheet, image, slide, and Word preview sizing, scrolling, zoom, navigation, and empty-document loading issues.
- Fixed feedback submissions from authenticated users in a same-origin local browser returning 401. Failed submissions retain their text and images for retry.
- Fixed room-member panel selection being lost when navigating away from a conversation and returning.
- Fixed workspace navigation changes displacing scheduled-task routes; scheduled tasks retain their dedicated page.
- Restored personal avatar editing inside the profile dialog, with nested editor backdrops and keyboard focus preserved.
- Fixed Agent deletion proceeding without checking team references and active work; affected teams can be opened from the warning.
- Fixed confusing Chinese error messages and task-state guidance, including localized network errors with dismissible feedback.

## 更新内容

本次发布将任务、会话和智能体管理整合到统一工作区，新增聊天资源选择和 DSH 持久记忆，并改善模型接入、桌面浏览及运行稳定性。

### 功能与优化

- **统一任务工作区**：选择智能体或团队发起任务，在会话旁管理智能体与团队，并搜索、置顶、重命名、归档或恢复历史会话。
- 通过五步向导创建自定义智能体，可选配指令、技能、连接器和知识库；保留模板创建入口，团队支持编辑描述。
- 宿主机 Codex、DSH 会话可独立设置模型、推理档位和初始工作目录，调整会话设置或重启后保留原生历史。任务创建后工作目录固定；团队和沙箱会话沿用原有执行设置。
- 通过独立面板管理协作房间成员、邀请及外部消息来源，查看房间任务和子任务进度；存在未解决结果时明确标记为**已结束（有遗留）**。
- **聊天中选择资源**：Codex、DSH 的单聊、线程、浮动聊天和新建任务支持选择技能、连接器和知识库。可在输入区搜索或通过斜杠选择；历史消息保留所选资源，使用时校验可用性。
- 在智能体资料页直接添加技能：从全局库选择、上传 ZIP，或查看市场技能文件后安装。市场安装与更新会更新全局副本，并为当前智能体启用。
- 在智能体资料页添加连接器，可绑定已配置的 App 资源，也可选择已有 MCP、手动配置或从市场安装 MCP。
- 通过独立的「知识库」页签启用已连接资源，或连接有权访问的 AgenticHub 知识库，无需离开智能体资料页。
- **DSH 持久记忆**：新增智能体独立的摘要、可检索手册、即时记忆工具和普通聊天后台提取。记忆默认启用，重启与重建后保留；后台提取需等待 61 分钟窗口，并非即时完成。仅在主动勾选时向模板附带摘要。
- Codex、DSH 共用受管 CLI 连接器包及配套技能。已有飞书安装迁移到统一流程，兼容的镜像预装包可离线导入；授权分开显示机器人与个人账号阶段，并提供取消及恢复操作。
- 连接器列表先展示已保存资源，再独立刷新各项健康状态，避免慢速发现阻塞其他资源；详情提供工具、配置及清理重试指引。
- 通过厂商 API／套餐预设、区域地址、官方 Key 入口和连接验证接入模型。高级设置支持自定义地址、请求头、模型 ID，以及 Responses、Chat Completions、原生 Messages 协议；凭证需匹配所选服务与区域。
- 新建智能体优先使用已连接的 OpenCSG `auto` 及可用的 OpenCSG 图片、视频模型，其他已连接服务作为后备。显式默认值及**不指定**会持久保存；未指定默认对话模型时，创建流程要求手动选择。
- 可恢复单个模型或整个提供方的默认上下文容量，通过「保存」应用。
- **每轮 Token 用量**：回复下方显示输入、输出合计，可查看可用的缓存与推理明细及所选模型。Codex、DSH 汇总本轮多次调用，用量随历史保存，并区分部分统计与不可用；选择 `auto` 时隐藏模型名称。
- 聊天共用文件、预览、网页、活动、线程和来源工具标签，提供文件搜索、清晰的格式图标和工作区路径导航。
- **桌面原生浏览器**：在 Chromium 面板中浏览网页，提供导航操作及独立于应用登录的持久浏览器配置，支持禁止 iframe 嵌入的网站。需要更新 Desktop 客户端；网页版继续使用 iframe，无法嵌入时可外部打开。
- 可在文件管理器、编辑器或终端中打开本地工作区文件与目录，并为生成附件选择建议的关联应用；远程访问保留路径限制和适用的后备操作。
- 通过消息时间线浏览长会话，预览用户提问与回复，并支持点击、拖动、滚轮和键盘导航。
- 智能体日志使用本地时间，回复诊断聚焦所选轮次，并补充所选模型与脱敏的上游失败信息。
- 模板支持中文显示名并保留智能体头像，明确区分官方、我的和公开模板。发布前保存本地快照，重试时可替换已有本地快照；云端智能体创建和管理转到 AgenticHub 继续操作。
- 新增内置 CSGClaw 自诊断技能，引导智能体结合运行证据和对应版本源码排查 Desktop、服务端、沙箱及集成问题。
- 成功完成回复后发送去重的桌面通知，支持持久保存提示音设置，并提供简洁的纯文本预览。
- 部署方可通过 `CSGCLAW_EXECUTION_MODE=standard|read_only` 设置 Codex 执行策略，默认 `standard`；无效值阻止启动，会话设置不能放宽服务端只读策略。
- 会话持久化跳过未变化数据的重复写入，变更仍同步、原子保存，减少不必要的磁盘写入。

### Bug 修复

- 修复客户端断开、取消请求失败或超时导致 Codex Worker 停止的问题；未确认取消时报告状态，并保留 Worker 供后续请求使用。
- 修复连接器恢复缓慢导致桌面启动超时，以及首次安装在 HTTP／MCP 就绪前启动 Manager 的问题。首次保存完整模型配置后会启动应运行的智能体，用户主动停止的智能体保持停止。
- 修复 Windows 重复清理已退出进程后，修改资料无法重启智能体的问题。已配置的离线 Codex 智能体可在聊天前恢复，**需要重建**提供确认入口。
- 修复 DSH 不支持所选推理档位时无法启动或恢复会话的问题。回退使用受支持的通用档位，不再将 `xhigh` 静默提升为运行时专属的 `max`，并保留已保存的选择。
- 修复 LLM 桥接层扩大 Qwen 等兼容服务输出 Token 上限的问题；Chat Completions 和 Responses 后备路径保留调用方指定值，由模型服务校验限制。
- 修复创建 CSGHub 模板 Worker 依赖即时在线模型探测的问题。模板创建仍校验运行参数与资源，模型错误在聊天时提示；创建弹窗先刷新模板再选择默认项。
- 修复新建智能体混用其他提供方模型或意外回退到本地 Lite 的问题，创建过程保留自定义指令与所选技能。
- 修复连接器健康状态受智能体绑定失败影响、检查成功或取消授权后仍显示旧错误，以及自定义 OpenCSG 登录站点无法识别的问题。
- 修复重启或重建工作区后丢失技能来源，以及知识库禁用再启用后丢失元数据的问题。资源重试保留已安装结果，更新市场技能时保留智能体的其他技能。
- 修复模板归属、发布状态和导航未及时刷新，以及新发布模板未出现在刷新列表中的问题。发布时排除本地技能进程锁，删除操作明确说明仅影响本地副本。
- 修复长会话输入卡顿、新任务回复未实时显示，以及自动滚动后回复被输入框遮挡的问题。浏览历史时保留阅读位置，有新回复时提供**查看最新**入口。
- 修复成员信息变化后任务无法停止、取消任务误报运行失败、Worker 退出后回复一直等待，以及通知拥堵影响房间任务派发或认领结果的问题。
- 修复 HTML、PDF、表格、图片、幻灯片和 Word 预览的尺寸、滚动、缩放、翻页及空文档加载问题。
- 修复已登录用户从同源本地浏览器提交反馈返回 401 的问题；提交失败后保留正文和图片以便重试。
- 修复离开会话再返回后，丢失房间成员面板选择的问题。
- 修复工作区导航调整影响定时任务路由的问题，定时任务保留独立页面。
- 恢复个人资料弹窗中的头像编辑，并正确保留嵌套编辑器遮罩和键盘焦点。
- 修复删除智能体前未检查团队引用和正在执行任务的问题，可从提示中打开相关团队。
- 修复中文错误提示和任务状态指引不清晰的问题，常见网络错误提供可关闭的本地化提示。
