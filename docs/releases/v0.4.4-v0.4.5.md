## 本周发布更新

本周发布带来原生桌面应用、远程 MCP 安装和实时 Agent 会话流，并进一步丰富多 Agent 协作、聊天交互及跨平台体验。

### 更新内容

- 新增适用于 Windows、macOS 和 Linux 的桌面应用及原生安装包，并支持服务自动启停；Windows 版还支持 Microsoft Store MSIX 打包。
- 支持通过身份认证发现和安装远程 MCP Server，并提供搜索、分页及规范化运行时配置，简化工具接入流程。
- 聊天室可开启免 @ 通知模式，开启后无需逐个 @Agent，消息就会发送给所有 Agent；该功能默认关闭。
- 单个 Agent 现在可以同时处理多个独立会话，并通过兼容 OpenAI API 的 SSE 实时返回结果，为 Agent 发布与共享提供基础能力。
- 聊天支持 Agent 主动提问，优化输入反馈和附件流程，并改善斜杠命令建议的无障碍体验。
- Agent 状态现在区分运行时就绪与生命周期，同时修复陈旧聊天室更新和关闭卡住问题，让状态判断和退出过程更可靠。
- 可选 OpenCSG 登录支持环境选择和自定义站点校验，并加强认证回调安全性。

### 涉及版本

- `v0.4.4`: 新增原生桌面应用、远程 MCP 安装、聊天室免 @ 通知及面向 Agent 发布与共享的单 Agent 多会话能力，并提升跨平台可靠性。
- `v0.4.5`: 为并发 Agent 会话新增实时流和 Agent 主动提问，并完善聊天、运行时状态、OpenCSG 登录及桌面体验。

## Weekly Release Update

This week’s releases introduce a native desktop app, remote MCP installation, and real-time agent session streaming, while expanding multi-agent collaboration, chat workflows, and cross-platform support.

### What's Changed

- Desktop apps and native installers are now available for Windows, macOS, and Linux, with managed service startup and shutdown; Windows also supports Microsoft Store MSIX packaging.
- Authenticated remote MCP server discovery and installation now include search, pagination, and normalized runtime configuration, making tools easier to connect.
- Rooms can optionally notify all agents without individual @mentions; this behavior is off by default.
- A single agent can now handle multiple independent sessions concurrently and stream results through an OpenAI-compatible SSE API, providing the foundation for agent publishing and sharing.
- Chat now allows agents to ask users questions, with clearer composer feedback, smoother attachment workflows, and accessible slash-command suggestions.
- Agent status now separates runtime readiness from lifecycle state, while stale room updates and shutdown hangs have been fixed for more dependable status and exit behavior.
- Optional OpenCSG login now supports environment selection and validated custom sites, with safer authentication callbacks.

### Covered releases

- `v0.4.4`: Added the native desktop app, remote MCP installation, optional room-wide notifications without @mentions, and single-agent multi-session support for agent publishing and sharing, with stronger cross-platform reliability.
- `v0.4.5`: Added real-time streaming for concurrent agent sessions and agent-generated questions, and improved chat, runtime status, OpenCSG login, and desktop behavior.
