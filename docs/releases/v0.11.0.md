## What's Changed

This release adds persistent agent memory, built-in browsing, richer cloud tasks, and more flexible team collaboration.

### Features & Improvements

- **Persistent agent memory:** Agents learn from eligible private chat history and update memory in the background. Memory survives runtime rebuilds and switches, is enabled by default in local, desktop, remote, and cloud deployments, and can be disabled per Agent. Edit, reset, clear, or forget learned details from the UI; group chats are excluded. Existing native Codex/DSH memory files are not imported; personal memory is rebuilt from eligible chat history.
- **Built-in Browser Use:** Ask Codex or DSH agents to navigate pages, fill forms, and take screenshots, with a live sidebar and user takeover. Chrome, Edge, or Chromium must be installed on the CSGClaw server. Public and loopback sites work by default; other private-network destinations require administrator opt-in. Browser sessions end on server restart; delivered screenshots remain available.
- **Roundtable collaboration (experimental):** Team members can read new room messages, announce their work, and coordinate as others contribute. The conversation shows active members and activity grouped by turn. Stopping a member pauses further room wakeups until the next user message.
- **Parallel Moderated collaboration:** Independent goals can run concurrently in one room, including separate task sessions assigned to the same worker. Dependent work still waits for Manager acceptance, and failed or stopped executions return to the Manager for replanning. Compatible Codex rooms can share one runtime concurrently; read-only and incompatible configurations retain isolated execution.
- **Cloud task attachments:** Send text with files or files alone and download generated results. File sharing has its own confirmation. Interrupted output transfers can resume after executor restarts without repeating execution, and partial delivery preserves reply text and successfully transferred files. File transfer requires matching Relay support and updated, reconnected executors.
- **Cloud profiles and resources:** View read-only live profiles for supported platform-hosted agents and select their skills, connectors, and knowledge bases when starting or continuing a task. Selections apply only to the current turn. Resource selection requires matching updates to Relay, the local client, and the cloud executor, plus an accessible platform instance endpoint.
- **Context controls:** See context usage while conversations are idle, retain the latest readings across restarts, and manually compact Codex or DSH conversations individually or in batches. Progress and results appear in conversation cards, with specific failure and skip reasons.
- **Reference-based media generation:** In Codex Web conversations, use attached images for image edits or a video's first frame, review generation details, and revise prompts before submission. Image edits require a compatible model and endpoint. References support PNG, JPEG, and WebP, up to **32 MiB combined**; image edits accept up to **16 images**, and first-frame video accepts one.
- **Per-request Session API models:** Codex clients can set `model` and `reasoning_effort` for each response request, including multipart uploads. Any chat model served by the configured provider can be selected, even if absent from its configured list. Omitted fields independently use Agent defaults; overrides preserve the profile and session history. Context-window changes automatically drain active turns and reload the runtime catalog.
- **Reviewed skill updates:** Inspect installed and target versions, release notes, and file changes before confirming an update or keeping the local copy. Updates synchronize matching Agent copies while preserving enablement. Agent skill cards and pickers also show installed versions and sources, including local ZIP versions.
- **More reliable template publishing:** Upload changed files in retryable batches with visible progress, preserving the published version marker until content uploads succeed. Community publication now accepts up to **100 MiB per template**, with the existing **50 MiB per-file limit**. Missing remote `.gitignore` files are recovered when needed without replacing existing rules.
- Browse, preview, reference, and sort workspace files from the task sidebar, and sort conversation attachments by date or name. Task creation shares chat attachment cards and searchable resource pickers; suggested commands preserve the existing draft for review, and the composer switches between stopping work and sending a follow-up based on draft content.
- Pin frequently used agents, teams, and templates, with collapsible pinned groups and search support in lists and task selection.
- Automatically name opted-in local single-agent task conversations after their first eligible successful reply, while preserving manual names and renames made during title generation.
- **OpenCSG site management:** Discover sign-in sites from the shared catalog and save, edit, test, or delete multiple custom sites locally. Saved sites remain available when discovery fails, manual entry remains supported, and account switching confirms the destination and uses the current login for cloud discovery and tasks.
- Community resource discovery shows recommendation badges and skill counts, loads local templates before remote results, reports catalog failures, and checks cloud agent availability in displayed batches. Agent Plaza descriptions expand into a dialog when truncated.
- **Updated runtimes and models:** Bundle Codex **0.167.1** with its platform helpers and resources, and update CLIProxyAPI to **v8.0.77**, adding GPT-6.2 Astra/Sol and Claude Fable 5.2/Haiku 5.5 to the applicable catalogs. Agents pinned to retired Codex models such as GPT-5.5 need a new model selection.
- **Filesystem permission default:** Codex standard mode and DSH now default to `danger-full-access`, allowing access outside the working directory within the runtime process's operating-system permissions. Explicit read-only or other permission selections remain respected.
- Permanently delete worker agents directly from their profile without archiving first, with exact-name confirmation. The Manager remains protected from deletion.
- Worker startup and runtime stderr now reach server stdout with runtime identifiers, and Codex protocol failures include request or turn details. Existing downloadable logs remain available, with recognized secrets redacted.
- Desktop Reload controls and standard keyboard shortcuts can refresh the interface and restore input focus.

### Bug Fixes

- Fixed Codex greetings after a failed turn reviving unrelated earlier requests, while retaining previous attachments when the user explicitly continues earlier work.
- Fixed repeated retries of oversized Codex model requests; these now stop with actionable guidance while transient errors remain retryable.
- Fixed answers continued across tool calls being lost, duplicated, or reordered. Opted-in Codex Session reasoning and DSH reasoning now stream incrementally without repeating completion snapshots.
- Fixed DSH turns reporting success without an answer or deliverable after exhausting output tokens. Output budgets honor provider limits and known DeepSeek capacities, and truncation or native failures are reported without automatic continuation.
- Fixed cloud conversations becoming unusable after an executor restart or lost session checkpoint. Recovery reuses the task with up to **16 KiB of recent completed text turns**; uncertain submissions require checking the outcome before resending.
- Fixed delayed Codex metadata writes replacing newer state and corrupt metadata blocking recovery; updates are atomic and damaged metadata is backed up before rebuilding.
- Fixed slow Manager startup delaying all worker restoration. New agents also recover stopped, failed, or unknown runtimes after resource setup, and stopping an Agent cancels its active work.
- Fixed Windows migration backups failing on unreadable generated DSH dependencies, directory links losing their type, and desktop startup or Browser Use hanging on helper handling. Desktop and Start menu shortcut creation also completes correctly.
- Fixed model connection checks and profile saves using mismatched protocols or addresses. New Kimi API, DeepSeek API, Alibaba Cloud Model Studio API, and Token Plan connections default to Responses; legacy ambiguous custom addresses require an explicit protocol, and Codex image settings save correctly with Chat Completions or Anthropic Messages providers.
- Fixed stale OpenCSG model catalogs after successful connection checks and outdated staging gateway credentials. Temporary Responses compatibility failures are rechecked after one minute, and model-not-found errors no longer disable Responses support.
- Fixed Volcengine Ark connection refreshes mixing configured private endpoints with public models. Separate Seedream image endpoint IDs can be configured and selected in Agent profiles; image-only connection checks verify the key, with endpoint access checked during generation.
- Fixed inline generated images resolving to the wrong attachment, restored Markdown Preview / Code switching, and restored interactive HTML attachments in the side browser. Large HTML source views remain responsive with line numbers, wrapping, and full-source copying.
- Fixed collaboration invitations offering cloud task identities; only agents in the local roster can be invited.
- Fixed offline cloud tasks accepting Enter submissions and workspace mention failures appearing as empty results. Pickers now distinguish loading, empty, and error states, with localized retry guidance.
- Fixed Roundtable rooms disappearing or becoming unresponsive during streamed activity by reducing redundant refreshes and history rewrites. Tool output stays bounded and scrollable without trapping conversation scrolling.
- Fixed graceful shutdown waiting for idle Agent MCP subscriptions; streams now close during shutdown while active tool calls retain their grace period.

## 更新内容

本次发布新增持久化智能体记忆、内置浏览器，扩展云端任务能力，并让团队协作更加灵活。

### 功能与优化

- **持久化智能体记忆**：从符合条件的私聊历史中学习，并在后台持续更新。记忆在运行时重建或切换后保留，本地、桌面、远程和云端部署均默认启用，可按 Agent 关闭。支持在界面中编辑、重置、清空记忆，或忘记从特定消息中学到的信息；群聊不参与学习。不导入原生 Codex/DSH 记忆文件，而是从符合条件的聊天历史重建个人记忆。
- **内置 Browser Use**：可让 Codex 或 DSH 智能体浏览网页、填写表单和截图，在侧栏实时查看并接管操作。CSGClaw 服务端需要安装 Chrome、Edge 或 Chromium。默认支持公网和回环地址，其他私网地址需要管理员启用。服务重启后浏览器会话结束，已发送的截图继续保留。
- **圆桌模式（实验性功能）**：团队成员可以读取群内新消息、说明分工，并根据同伴进展协调工作。会话显示活跃成员，按轮次组织活动。停止某个成员后暂停房间后续唤起，直到用户再次发言。
- **主持模式并行协作**：同一房间的独立目标可以同时推进，同一 Worker 也能在不同任务会话中并行工作。依赖任务仍需等待 Manager 验收，执行失败或停止后交回 Manager 调整计划。配置兼容的 Codex 房间可共享运行时并行执行；只读及不兼容配置保留隔离执行方式。
- **云端任务附件**：支持文字加文件或仅文件输入，并下载生成的结果。文件共享单独确认；执行端重启后可恢复中断的结果传输，无需重复执行任务，部分文件传输失败时保留回复文字和已成功传输的文件。文件传输需要配套的 Relay 支持，以及已更新并重新连接的执行端。
- **云端档案与资源**：支持查看平台托管智能体的实时只读档案，在新建或继续任务时选择其技能、连接器和知识库。选择仅对当前轮次生效。资源选择需要同步更新 Relay、本地客户端和云端执行端，并具备可访问的平台实例端点。
- **上下文控制**：会话空闲时仍可查看上下文用量，最近读数在重启后保留，支持对 Codex 或 DSH 会话单独或批量手动压缩。进度与结果通过会话卡片展示，并说明失败及跳过原因。
- **参考图片生成媒体**：在 Codex Web 会话中使用附件图片进行编辑，或作为视频首帧；提交前可确认生成详情并修改提示词。图片编辑需要兼容的模型和接口。参考图片支持 PNG、JPEG、WebP，**合计最多 32 MiB**；图片编辑最多接受 **16 张图片**，视频首帧接受一张。
- **Session API 按请求选择模型**：Codex 客户端可为每次响应请求设置 `model` 和 `reasoning_effort`，支持 multipart 上传。可选择当前服务商提供的任意对话模型，即使它不在已配置列表中。未填写的字段分别使用 Agent 默认值，不修改档案或丢失会话历史；上下文窗口变化时自动等待活跃轮次结束并重新加载运行时目录。
- **审核后更新 Skill**：确认更新或保留本地副本前，可查看已安装版本、目标版本、发布说明和文件变化。更新同步到匹配的 Agent 副本，并保留启用状态。Agent 技能卡片和选择器同时展示版本与来源，包括本地 ZIP 版本。
- **更可靠的模板发布**：分批上传变更文件，支持重试并显示进度，内容上传完成后才更新已发布版本标记。社区发布现支持**每模板最多 100 MiB**，保留**每文件 50 MiB 上限**。远端缺少 `.gitignore` 时按需恢复，不替换已有规则。
- 支持从任务侧栏浏览、预览、引用和排序工作区文件，并按日期或名称排序会话附件。新建任务复用聊天附件卡片和可搜索资源选择器；插入建议命令时保留原草稿供检查，输入框根据是否有草稿切换停止执行与发送后续消息操作。
- 支持置顶常用 Agent、团队和模板，列表及任务选择器中的置顶分组可折叠，并支持搜索。
- 启用自动命名的本地单 Agent 任务会话，在首次符合条件的成功回复后生成标题，保留手动名称及生成期间发生的重命名。
- **OpenCSG 站点管理**：从共享目录发现登录站点，在本地保存、编辑、测试或删除多个自定义站点。目录不可用时仍可选择已保存站点或手动输入；切换账号前确认目标，云端发现与任务使用当前登录身份。
- 社区资源发现展示推荐标记与技能数量，优先加载本地模板，显示目录加载错误，并按已展示批次检查云端智能体在线状态。智能体广场中被截断的描述可在对话框展开查看。
- **运行时与模型升级**：内置 Codex 升级至 **0.167.1**，包含各平台辅助程序与资源；CLIProxyAPI 升级至 **v8.0.77**，在对应目录中新增 GPT-6.2 Astra/Sol、Claude Fable 5.2/Haiku 5.5。固定使用 GPT-5.5 等已退役 Codex 模型的 Agent 需要重新选择模型。
- **文件系统权限默认值**：Codex 标准模式和 DSH 默认使用 `danger-full-access`，可在运行时进程的操作系统权限范围内访问工作目录之外的路径。明确选择的只读及其他权限模式继续生效。
- 支持从档案直接永久删除 Worker Agent，无需先归档，操作时必须输入完整名称确认。Manager 仍禁止删除。
- Worker 启动及运行期间的 stderr 输出到服务端 stdout，附带运行时标识；Codex 协议错误包含请求或轮次详情。原有日志下载继续可用，已识别的密钥会被隐藏。
- 桌面端新增重新加载操作和标准快捷键，刷新界面后恢复输入焦点。

### Bug 修复

- 修复 Codex 在失败轮次后的问候触发无关旧请求的问题；用户明确要求继续此前工作时，仍可使用先前附件。
- 修复 Codex 对过大模型请求反复重试的问题，改为停止并给出处理建议，临时错误仍可重试。
- 修复跨工具调用继续输出的答案丢失、重复或顺序错误的问题。启用相应选项的 Codex Session 思考内容及 DSH 思考内容可增量输出，不重复发送完成快照。
- 修复 DSH 耗尽输出额度、没有答案或交付文件时仍显示成功的问题。输出预算遵循服务商限制和已知 DeepSeek 容量，截断或原生执行失败时明确报错，不自动继续执行。
- 修复执行端重启或会话检查点丢失后云端会话无法继续的问题。恢复时复用原任务，最多携带 **16 KiB 最近已完成轮次的文字**；提交结果不确定时，需要先核实执行结果再重新发送。
- 修复 Codex 延迟写入覆盖较新元数据，以及元数据损坏阻塞恢复的问题。更新采用原子写入，重建前备份损坏数据。
- 修复 Manager 启动缓慢导致全部 Worker 延迟恢复的问题。新建 Agent 配置资源后会恢复已停止、失败或未知的运行时；停止 Agent 时取消其活跃工作。
- 修复 Windows 迁移备份因生成的 DSH 依赖不可读而失败、目录链接类型丢失，以及桌面启动或 Browser Use 在辅助程序处理时卡住的问题。桌面和开始菜单快捷方式也能正常完成创建。
- 修复模型连接检查与档案保存使用不匹配协议或地址的问题。新建 Kimi API、DeepSeek API、阿里云百炼 API 和 Token Plan 连接默认使用 Responses；旧自定义地址无法明确推断协议时要求选择。Codex 使用 Chat Completions 或 Anthropic Messages 服务商时，图片设置可正常保存。
- 修复连接检查成功后 OpenCSG 模型目录仍过期，以及预发布环境网关凭据地址过旧的问题。Responses 临时兼容性失败在一分钟后重新检查，模型不存在的错误不再禁用 Responses 支持。
- 修复火山方舟连接刷新混入公共模型的问题，配置私有接入点后仅展示这些接入点。可单独配置 Seedream 图片接入点并在 Agent 档案选择；仅配置图片接入点时，连接检查验证 Key，生成时验证接入点权限。
- 修复生成图片的行内引用匹配到错误附件的问题，恢复 Markdown 附件的预览与代码切换，以及侧栏浏览器中的交互式 HTML 附件。大型 HTML 源码预览保持响应，支持行号、换行和复制完整源码。
- 修复协作邀请出现云端任务身份的问题，仅允许邀请本地成员列表中的 Agent。
- 修复云端智能体离线时仍可按 Enter 提交，以及文件引用加载失败显示为空列表的问题。选择器区分加载中、空结果和错误状态，并提供本地化重试提示。
- 修复流式活动期间圆桌房间消失或响应迟缓的问题，减少重复刷新和历史重写。工具输出限制展示高度并支持滚动，到达边缘后可继续滚动会话。
- 修复正常关闭服务时等待空闲 Agent MCP 订阅的问题；关闭期间及时结束订阅流，活跃工具调用仍保留宽限时间。
