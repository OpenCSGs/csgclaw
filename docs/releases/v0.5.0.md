## What's Changed

This release adds secure read-only agent execution, the Agent Engine and Session API foundation, desktop update channels and turn notifications, and stronger Skill and template workflows, while hardening upgrades, runtime behavior, the Web UI, and cross-platform packaging.

### Features & Improvements

- Added configurable secure read-only execution for Codex workers, enforcing read-only sandbox, approval, tool, environment, Skill, and MCP boundaries and preserving the mode through templates.
- Introduced Agent Engine decoupling and the core Session API path, including dedicated session storage and updated Web demo flows.
- Added release and beta update channels for Server and Desktop, turn-completion notifications, signed macOS packages, and clearer channel-switching controls.
- Streamlined release operations with targeted manual desktop packaging and clearer alpha, beta, and stable publishing flows.
- Accelerated remote Skill and template downloads through Hub archive APIs, with archive validation and fallback compatibility for older Hub deployments.
- Improved community template publishing with environment-aware registries, persistent review state, and actionable duplicate-name and sensitive-content feedback.
- Refined agent action menus and conversation connector settings, including responsive layouts and clearer GitLab save feedback.

### Bug Fixes

- Made update-channel switching transactional and stabilized Windows auto-upgrades with native installer coordination, runtime-lock handling, reliable relaunch and foreground behavior, and better diagnostics.
- Hardened agent lifecycle and runtime handling by preventing restart-state leakage, improving model and runtime status reporting, deferring BoxLite checks until use, and reporting sandbox cleanup failures clearly.
- Restored OpenCSG authentication and billing recovery by allowing authorization retries, refreshing rotated API keys, improving network and payment errors, and preserving recharge actions through profile failures.
- Fixed directory selection by hiding unsupported browser controls and correcting Windows picker focus and UTF-8 path handling.
- Fixed Windows startup migrations by excluding `runtime.lock` from backup copies.
- Fixed agent profile UX by safely handling unsaved edits during navigation, improving model-loading retries, and removing channel-only activity from public profiles.
- Fixed notification and deployed-Web cleanup issues by deleting orphaned notification rooms, reloading stale route chunks, and removing duplicate room names from direct-chat completion notifications.
- Fixed team member dialogs and rendering so managers stay selected and avatars remain constrained.
- Fixed remote Skill links to open the correct OpenCSG site and ignored unsupported Hub registry configurations.
- Corrected multi-architecture Docker and CI builds to honor the selected target platform.

## 更新内容

本次发布新增安全只读 Agent 执行模式、Agent Engine 与 Session API 基础能力、桌面端更新通道与执行完成通知，并增强 Skill 与模板工作流，同时提升升级、运行时、Web UI 和跨平台构建的稳定性。

### 功能与优化

- 新增可配置的 Codex Worker 安全只读执行模式，强制限制沙箱、审批、工具、环境、Skill 和 MCP 权限，并支持通过模板继承该模式。
- 引入解耦后的 Agent Engine 和 Session API 核心链路，包括独立的会话存储和更新后的 Web 演示流程。
- 为 Server 和 Desktop 新增 release、beta 更新通道与执行完成通知，并提供签名 macOS 安装包和更清晰的通道切换控件。
- 优化发布流程，支持定向桌面端手动打包，并明确 alpha、beta 和 stable 发布方式。
- 通过 Hub 归档 API 加速远程 Skill 和模板下载，同时支持归档校验及旧版 Hub 回退兼容。
- 优化社区模板发布流程，支持根据当前环境选择注册表、保留审核状态，并为重名和敏感内容提供可操作的反馈。
- 优化 Agent 操作菜单与会话连接器设置，包括响应式布局和更清晰的 GitLab 保存反馈。

### Bug 修复

- 将更新通道切换改为事务式操作，并通过原生安装协调、运行时锁处理、可靠的重启与窗口前置以及更完整的诊断信息，提升 Windows 自动升级稳定性。
- 加强 Agent 生命周期和运行时处理，避免重启状态泄漏，改善模型与运行时状态反馈，将 BoxLite 检查推迟到实际使用时，并清晰提示沙箱清理失败。
- 恢复 OpenCSG 授权与计费故障后的处理流程，支持重新发起授权、刷新轮换后的 API Key、改善网络与支付错误提示，并在配置更新失败时保留充值入口。
- 修复目录选择问题：在不支持的浏览器中隐藏相关控件，并修正 Windows 目录选择器的窗口焦点和 UTF-8 路径处理。
- 在配置迁移备份中排除 `runtime.lock`，修复 Windows 启动失败问题。
- 修复 Agent 配置页面体验，包括妥善处理导航时的未保存修改、改进模型加载重试界面，以及从公开配置页移除仅适用于频道的活动信息。
- 修复通知与已部署 Web 更新问题，包括清理遗留通知房间、自动重新加载过期路由资源，以及避免私聊完成通知重复显示 Agent 名称。
- 修复团队成员弹窗和渲染问题，确保 Manager 始终保持选中，成员头像尺寸不再溢出。
- 修复远程 Skill 链接，使其打开正确的 OpenCSG 站点，并忽略不受支持的 Hub 注册表配置。
- 修复多架构 Docker 与 CI 构建，确保使用指定的目标平台。
