## What's Changed

This release focuses on multi-agent collaboration, image generation, and file handling, with improvements to resource management and everyday reliability.

### Features & Improvements

- **Manager-led group collaboration**: Added on-demand rooms where Manager breaks goals into tasks, assigns Workers, and reviews and summarizes their results. Users can view task progress from the chat. New rooms default to this mode; existing rooms without a type continue to use free discussion.
- **Dedicated image generation models**: Configure an image model separately from an Agent's chat model to generate, save, and copy images in Codex Web UI conversations, with retries for failed generation or delivery.
- **Reuse files already shared in a room**: Agents can find and download historical attachments by filename or source message, helping Workers reuse files during task handoffs and reducing repeated uploads. These operations are also available through the CLI and API.
- Added OpenCSG MCP Gateway support so configured MCP tools can process files in an Agent's workspace, with account credentials supplied at runtime.
- Enabled Codex Agents to upload workspace files to configured MCP services for subsequent tool processing.
- Added HTML attachment previews so users can view generated pages and switch to highlighted source code. Previews block scripts and external resources.
- Increased text preview limits to 32 MiB and chat attachment limits to 100 MiB per file and 256 MiB per message, with better support for previewing large remote-template files.
- Redesigned resource and model-provider pages to make resources easier to find and manage, with local Skill deletion and smoother MCP and knowledge-base setup.
- Added a consistent OpenCSG sign-in flow with environment selection when authentication is needed, and more accurate prompts after login expires or the Manager's model changes.
- Improved Skill list loading in Agent profiles so an unreadable or invalid Skill does not block other entries.
- Improved Agent reliability by preserving extension settings during runtime replacement and refining Feishu tool setup and retries, cancellation, and interactive response handling.

### Bug Fixes

- Fixed managed Codex Agent startup failures triggered by unused model-provider settings copied from the host, including in read-only mode.
- Fixed custom instructions from Codex templates being lost when the runtime first refreshed.
- Corrected Web UI template selection so new Agents default to Codex; the built-in OpenClaw template remains available through its detail page.
- Fixed Windows tray, taskbar, and shortcut icons showing the wrong theme at startup or after theme changes.
- Fixed slow shutdown when Web UI event streams stayed open. A second Ctrl+C can now terminate stalled cleanup.

## 更新内容

本次发布重点增强多 Agent 协作、图片生成与文件处理能力，并改善资源管理和日常使用的稳定性。

### 功能与优化

- **Manager 主导的群聊协作**：新增「按需发言」房间，Manager 根据目标拆分任务、安排 Worker 执行并验收汇总，用户可以在聊天中查看任务进度。新建房间默认使用此模式，未设置类型的历史房间继续使用自由发言模式。
- **独立的图片生成模型**：可为 Agent 单独配置图片生成模型，在 Codex Web UI 会话中生成、保存和复制图片，并对失败的生成或投递操作进行重试。
- **复用房间中已有的文件**：Agent 可按文件名或来源消息检索并下载历史附件，帮助 Worker 在任务交接时继续使用相关文件，减少重复上传。CLI 和 API 同样支持这些操作。
- 新增 OpenCSG MCP Gateway 接入，通过配置即可让 MCP 工具处理 Agent 工作区中的文件，账号凭证由运行时提供。
- 支持 Codex Agent 将工作区文件上传至已配置的 MCP 服务，供后续工具处理。
- 新增 HTML 附件预览，可直接查看生成的页面，并切换查看高亮源码。预览会阻止脚本与外部资源加载。
- 将文本预览上限提升至 32 MiB，聊天附件上限提升至单文件 100 MiB、单条消息 256 MiB，并改善大型远端模板文件的预览。
- 重新设计资源与模型提供方页面，让资源更易查找和管理，支持删除本地 Skill，并优化 MCP 与知识库的添加流程。
- 在需要认证时提供统一的 OpenCSG 登录入口与环境选择，并改善登录失效或 Manager 切换模型后的提示准确性。
- 改善 Agent 资料页的技能列表加载，单个无法读取或无效的 Skill 不再阻塞其他条目。
- 改善 Agent 运行稳定性，在替换运行时时保留扩展配置，并优化飞书工具初始化与重试，以及取消和交互响应处理。

### Bug 修复

- 修复从宿主复制的无用模型提供方配置导致托管 Codex Agent 启动失败的问题，包括只读模式下的启动失败。
- 修复从 Codex 模板创建 Agent 后，首次刷新运行时可能丢失自定义指令的问题。
- 修正 Web UI 模板选择，新建 Agent 默认使用 Codex；仍可从内置 OpenClaw 模板详情页创建 Agent。
- 修复 Windows 托盘、任务栏和快捷方式图标在启动或切换主题后显示不匹配的问题。
- 修复 Web UI 事件流保持连接时关闭缓慢的问题，并支持再次按 Ctrl+C 终止卡住的清理过程。
