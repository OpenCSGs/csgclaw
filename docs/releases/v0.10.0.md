## What's Changed

### Features & Improvements

- **Cloud agents:** Browse community agents after signing in to OpenCSG, add them to My agents, and start tasks in the shared conversation workspace. Cloud tasks accept text input, show a privacy confirmation before sending, and return results when execution completes.
- **Relay publishing:** Publish host Codex and DSH agents through the local API or `--auto-publish`, using the current OpenCSG site's credentials. Publication state and pending synchronization survive restarts; platform workers reuse their existing community instance. The Web UI provides publication status, cancellation, and unpublish controls; its new-publication action is hidden in this release.
- **Shared collaboration workspaces:** New collaboration rooms share a working directory and receive a saved copy of the team's collaboration guide for the Manager and participating agents. Existing rooms retain their directories, and each agent retains its model and permissions. Manager guidance includes planning required reviews as dependent tasks.
- **Conversational scheduling:** Create and edit scheduled tasks through Manager conversations in a writable execution mode, selecting the executor and confirming the time and instructions before saving. Each automatic or manual run has a dedicated conversation linked from run history, with the latest result available in schedule details.
- **Agent archiving:** Archive and restore local worker agents through the Web UI, CLI, or API. Archiving stops execution and pauses schedules, which remain paused after restoration. Permanent deletion requires an archived agent and exact-name confirmation, preserves working files and collaboration history, and removes direct conversations.
- Templates can supply default models and reasoning effort, with explicit creation choices taking precedence and credentials supplied by the current environment.
- **Template versions:** Save, preview, switch, and manage local template revisions, including on Windows. History remains available until manually deleted; the active revision is protected from deletion, and revision numbers continue increasing.
- Publish the active template snapshot to the community in one batch update, track its published version, and synchronize its display name. Publication validates a **50 MiB limit per file** before uploading; snapshots may exceed 50 MiB in total when each file meets the limit.
- Discover and reuse skills from supported local tools through source links, with source filtering, active-version details, update indicators, and manual rescanning. Adding a discovered skill to an agent creates that agent's workspace snapshot.
- **Persistent session attachments:** Session APIs accept multipart uploads, inline Base64 files, and reusable attachment IDs. Saved files remain available across turns and after cancellation, and downloads reflect workspace edits. Requests support up to **10 nonempty files, 1 GiB per file, and 2 GiB combined**; file submissions require credentials when service authentication is enabled.
- Session API clients can enable interactive questions per request with `user_input: true`, retrieve pending questions, and submit answers to continue execution. These operations require valid credentials when service authentication is enabled. Text clarification is the default; detached questions without an explicit deadline expire after 24 hours.
- **Turn diagnostic exports:** Download a streamed ZIP containing model exchanges, execution context, environment details, file evidence, and correlated logs. Recognized credentials are redacted, unavailable evidence is marked, and clipboard copies remain JSON.
- A bilingual interactive onboarding guide introduces the workspace and can be reopened from Settings → Feedback & Help. Acknowledgment follows guide content revisions, so unchanged content stays acknowledged across application upgrades; Windows window controls and the exit button remain usable.
- Existing OpenClaw and PicoClaw agents migrate to Codex with their identities, model settings, MCP selections, custom skills, messages, and working files preserved. Successfully migrated agents start automatically once model configuration is complete; later user-requested stops are preserved.
- Added OpenEast Community as a preset in the OpenCSG connection dialog.
- Agent mention names now support up to 64 Unicode characters.

### Bug Fixes

- Fixed long Codex turns being incorrectly timed out during reasoning or other runtime activity. Codex turns and session API responses now run without a server-imposed duration limit, while retaining cancellation and runtime-failure handling.
- Fixed session streams losing or reordering tool results and final answers when completion events are delayed or missing. Tool results retain their call IDs, recoverable Codex output follows native item order, and worker transport failures release pending requests.
- Codex file-publication failures now return recoverable errors, allowing the agent to correct the path and retry within the same turn.
- Fixed truncated JSON in large model requests. The LLM proxy accepts request bodies up to **128 MiB** and returns HTTP 413 when the limit is exceeded.
- Fixed startup using stale host callback URLs after listener changes. Offline agents expose their Start action, and startup failures show complete error details.
- Fixed unconfigured Managers remaining unavailable after connecting a model or signing in to OpenCSG. Setup can complete automatically, and connected models remain usable after restart.
- Fixed template instruction edits disappearing during navigation. Drafts are retained within the current page session, save/discard states are explicit, and refreshing or closing with unsaved changes shows a warning.
- Restored previews for PPTX files containing references to deleted parts, DOCX files containing UTF-16 XML, and Chinese PDFs requiring bundled preview resources.
- Fixed Feishu connection startup, authorization links, retries, and cancellation on Windows.
- Fixed Windows DSH plugin paths and allowed additional startup time for the runtime.
- Fixed Windows desktop input losing focus after native confirmation dialogs and tray quit failing while cleaning up a destroyed window.
- Fixed missing skill descriptions when skill definitions use Windows CRLF line endings.
- Fixed desktop OpenCSG sign-in rejecting HTTP site URLs, retaining custom-site confirmation and URL validation.
- Fixed task member mentions disappearing during task creation or editing, and made scheduled-task reviews show every executor with current, clearly labeled times.
- Kept skill and resource picker actions accessible in small or scaled desktop windows, and restored composer borders and focus indicators in Windows 7.

## 更新内容

### 功能与优化

- **云端 Agent**：登录 OpenCSG 后可浏览社区 Agent，添加到「我的智能体」，并在统一的会话工作区中发起任务。云端任务接受文本输入，发送前显示隐私确认，执行完成后返回结果。
- **Relay 发布**：通过本地 API 或 `--auto-publish` 发布运行于宿主环境的 Codex、DSH Agent，使用当前 OpenCSG 站点凭证。发布状态和待同步操作在重启后保留，平台 Worker 复用已有社区实例。Web UI 提供发布状态、取消发布和撤销发布操作；此版本隐藏新增发布入口。
- **共享协作工作目录**：新建协作房间共享工作目录，并为 Manager 和参与 Agent 保存团队协作指南副本。已有房间保留原目录，各 Agent 保留自己的模型与权限。Manager 指令包含将必要审核安排为依赖任务的要求。
- **通过对话管理定时任务**：Manager 在可写执行模式下支持创建和编辑定时任务，保存前选择执行者并确认时间与指令。每次自动或手动运行都有独立会话，可从运行历史打开，并在定时任务详情中查看最新结果。
- **Agent 归档**：支持通过 Web UI、CLI 或 API 归档和恢复本地 Worker Agent。归档会停止执行并暂停定时任务，恢复后这些定时任务继续保持暂停。永久删除需要 Agent 已归档，并确认完整名称；删除后保留工作文件与协作历史，移除直接会话。
- 模板可以提供默认模型与思考强度，创建时明确选择的配置优先生效，凭证由当前环境提供。
- **模板版本管理**：支持保存、预览、切换和管理本地模板版本，兼容 Windows。版本历史保留至手动删除，当前使用的版本受到删除保护，版本编号持续递增。
- 当前模板版本可通过一次批量更新发布到社区，记录已发布版本并同步显示名称。上传前检查**每文件 50 MiB 上限**；每个文件符合限制时，模板总量可以超过 50 MiB。
- 自动发现支持的本地工具中的 Skill，通过来源链接复用，支持来源筛选、当前版本详情、更新提示和手动重新扫描。将发现的 Skill 添加到 Agent 时，会创建该 Agent 的工作区副本。
- **持久保存的会话附件**：Session API 支持 multipart 上传、内联 Base64 文件及可重复引用的附件 ID。已保存文件可跨轮次使用，取消执行后继续保留，下载内容随工作区文件修改而更新。每次请求最多支持 **10 个非空文件，单文件 1 GiB，合计 2 GiB**；启用服务认证时，提交文件需要有效凭证。
- Session API 客户端可在每次请求中通过 `user_input: true` 启用交互问题，查询待回答问题并提交答案以继续执行。启用服务认证时，这些操作均需要有效凭证。默认使用文本进行澄清；没有明确期限的 detached 问题在 24 小时后过期。
- **轮次诊断导出**：流式下载 ZIP，包含模型交互、执行上下文、环境信息、文件证据和关联日志。已识别的凭证会被隐藏，不可获取的证据会有明确标记，复制到剪贴板的内容保持 JSON 格式。
- 新增中英文交互式新手引导，可从「设置 → 反馈与帮助」重新打开。阅读确认按引导内容版本保存，应用升级后继续保留对相同内容的确认；Windows 窗口控制按钮与引导退出按钮均可正常使用。
- 已有 OpenClaw、PicoClaw Agent 迁移到 Codex，保留身份、模型设置、MCP 选择、自定义 Skill、消息和工作文件。迁移成功且模型配置完整后自动启动，之后由用户执行的停止操作继续保留。
- OpenCSG 连接对话框新增东方社区预设。
- Agent 提及名称支持最多 64 个 Unicode 字符。

### Bug 修复

- 修复 Codex 在长时间思考或其他运行活动中被错误判定超时的问题。Codex 轮次和 Session API 响应取消服务端执行时长限制，保留取消执行及运行失败处理。
- 修复完成事件延迟或缺失时，会话流遗漏工具结果、最终答案或出现顺序错误的问题。工具结果保留调用 ID，可恢复的 Codex 输出遵循原始事件顺序，Worker 通信失败时释放待处理请求。
- Codex 发布文件失败时返回可恢复的错误，Agent 可以修正路径，并在同一轮次内重试。
- 修复大型模型请求的 JSON 被截断的问题。LLM 代理接受最大 **128 MiB** 的请求正文，超限返回 HTTP 413。
- 修复监听地址变化后启动仍使用旧宿主回调地址的问题。离线 Agent 显示启动操作，启动失败时展示完整错误详情。
- 修复未配置的 Manager 在连接模型或登录 OpenCSG 后仍不可用的问题。设置流程可以自动完成，已连接模型在重启后继续可用。
- 修复页面导航期间模板指令修改丢失的问题。草稿在当前页面会话内保留，明确显示保存与放弃状态，存在未保存内容时刷新或关闭页面会显示提醒。
- 恢复包含已删除部分引用的 PPTX、包含 UTF-16 XML 的 DOCX，以及需要内置预览资源的中文 PDF 的预览。
- 修复 Windows 上飞书连接启动、授权链接、重试和取消操作的问题。
- 修复 Windows 上 DSH 插件路径问题，并增加运行时启动等待时间。
- 修复 Windows 桌面端关闭原生确认对话框后输入失去焦点，以及从托盘退出时清理已销毁窗口导致失败的问题。
- 修复 Skill 定义使用 Windows CRLF 换行时描述缺失的问题。
- 修复桌面端 OpenCSG 登录拒绝 HTTP 站点地址的问题，保留自定义站点确认和 URL 校验。
- 修复创建或编辑任务时成员提及丢失的问题；定时任务确认界面展示全部执行者，并使用最新且标记明确的时间。
- 在较小窗口或缩放后的桌面窗口中保持 Skill 与资源选择器操作可见，并恢复 Windows 7 的输入框边框和焦点提示。
