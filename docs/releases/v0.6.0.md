## What's Changed

This release advances the Agent Engine channel migration, adds richer Feishu and chat file workflows, introduces persistent Codex memory and AgenticHub knowledge bases, and improves template publishing, diagnostics, desktop behavior, and Web UI reliability.

### Features & Improvements

- Advanced the Agent Engine migration for Agent administration and the built-in IM adapter, preserving lifecycle and conversation behavior while improving backpressure recovery, cancellation, and interactive prompt handling.
- Routed hosted Feishu workers through a dedicated Agent Engine channel with thread, quote, and document-comment context, bounded intake, streaming Markdown replies, retry handling, and structured diagnostics.
- Added end-to-end Feishu file transmission so Agents can receive images and files and return generated artifacts with enforced size, count, and quota limits.
- Added isolated per-worker `lark-cli` bindings with automatic setup, status and initialization controls, trusted local callbacks, platform-appropriate paths, credential sourcing, and one-worker-per-bot enforcement.
- Added persistent Codex runtime memory with a dedicated Web UI tab, refresh checkpoints for active conversations, and memory snapshot and restore support in Agent templates.
- Added durable delivery of Agent-generated chat attachments and secure multi-format previews with syntax highlighting, synchronized PDF and PPTX navigation, stable fullscreen and layout behavior, and responsive document controls.
- Integrated AgenticHub LLM Wiki knowledge bases, allowing signed-in users to discover managed MCP resources, bind them to Agents, preserve those bindings through templates, and refresh Agent snapshots directly from Hub metadata.
- Simplified Agent template manifests by removing deprecated fields and deriving built-in roles from the registry while preserving Manager and Worker behavior.
- Made template publishing safer by limiting workspace exports to supported instruction files, and expanded the template memory view for easier inspection.
- Made browser launch opt-in for `csgclaw serve` through `--browser`, keeping command-line restarts from opening unwanted Web UI tabs.
- Extended Windows desktop diagnostics with redacted Agent and runtime data plus resilient partial collection.
- Added theme-aware Windows tray icons that follow application and system appearance changes.
- Refined Agent and human profile interactions with accessible previews, Agent side-drawer navigation, responsive identity layouts, stable post-delete selection, and flicker-free deletion behavior.

### Bug Fixes

- Improved template publishing and deployment errors with sensitive-file paths, localized structured messages, preserved review details, and clearer retry behavior.
- Prevented Windows read-only Agent startup failures while preserving sandbox and root-deny protections.
- Kept Windows system proxy settings from breaking non-provider network access by scoping proxy behavior to the configured coding providers.
- Restored Windows notifications for completed scheduled tasks by using short, stable notification identifiers.
- Prevented duplicate chat sends across rapid clicks, retries, normal messages, and thread replies.
- Fixed realtime Web events for root and subpath deployments by resolving SharedWorker endpoints before opening the event stream.
- Corrected navigation to Skill and resource detail pages.
- Preserved existing Manager configuration when rebuilding from the Web UI.
- Made Codex Agent restarts idempotent when the tracked process has already exited, avoiding Windows process-open failures.

## 更新内容

本次发布继续推进 Agent Engine 频道迁移，增强飞书与聊天文件工作流，引入 Codex 持久记忆和 AgenticHub 知识库，并改善模板发布、诊断、桌面端体验及 Web UI 稳定性。

### 功能与优化

- 推进 Agent 管理和内置 IM 适配器向 Agent Engine 迁移，在保留生命周期与会话行为的同时，改善背压恢复、取消和交互式提问处理。
- 将托管飞书 Worker 接入独立的 Agent Engine 频道，支持线程、引用消息和文档评论上下文，并增强有界并发接入、Markdown 流式回复、重试和结构化诊断。
- 新增端到端飞书文件传输，Agent 可接收图片和文件并返回生成产物，同时实施文件大小、数量和配额限制。
- 新增隔离的逐 Worker `lark-cli` 绑定，支持自动配置、状态与初始化操作、可信本地回调、适配各平台的路径、凭证获取，以及一个机器人仅绑定一个 Worker 的约束。
- 新增 Codex 运行时持久记忆，提供独立 Web UI 标签页、活跃会话记忆刷新检查点，以及 Agent 模板中的记忆快照与恢复能力。
- 新增 Agent 生成文件的持久聊天附件投递，并提供安全的多格式预览、语法高亮、同步的 PDF 与 PPTX 导航、稳定的全屏与布局行为，以及响应式文档控件。
- 集成 AgenticHub LLM Wiki 知识库，登录用户可发现托管 MCP 资源、将其绑定到 Agent、通过模板保留这些绑定，并直接从 Hub 元数据刷新 Agent 快照。
- 简化 Agent 模板清单，移除弃用字段并从注册表推导内置角色，同时保留 Manager 与 Worker 行为。
- 将模板发布的工作区内容限制为受支持的指令文件，并扩大模板记忆查看区域，提升发布安全性和可读性。
- 将 `csgclaw serve` 的浏览器启动改为通过 `--browser` 显式开启，避免命令行重启时自动打开多余的 Web UI 标签页。
- 扩展 Windows 桌面端诊断，加入脱敏的 Agent 与运行时数据，并支持单项采集失败时继续生成诊断包。
- 新增跟随应用与系统外观变化的 Windows 托盘图标。
- 优化 Agent 与用户资料交互，提供无障碍预览、Agent 侧边抽屉导航、响应式身份布局、删除后的稳定选中状态，以及无闪烁的删除行为。

### Bug 修复

- 改进模板发布与部署错误处理，展示敏感文件路径，提供本地化结构化提示，保留审核详情，并明确重试状态。
- 修复 Windows 只读 Agent 启动失败，同时保留沙箱与根目录拒绝访问保护。
- 将 Windows 系统代理行为限制在已配置的编程 Provider，避免影响其他网络访问。
- 通过短小且稳定的通知标识，恢复 Windows 定时任务完成通知。
- 防止快速点击、重试、普通消息和线程回复导致聊天消息重复发送。
- 在打开事件流前解析 SharedWorker 端点，修复根路径和子路径部署下的 Web 实时事件连接。
- 纠正 Skill 与资源详情页导航。
- 从 Web UI 重建 Manager 时保留现有配置。
- 当所跟踪进程已经退出时，使 Codex Agent 重启保持幂等，避免 Windows 进程打开失败。
