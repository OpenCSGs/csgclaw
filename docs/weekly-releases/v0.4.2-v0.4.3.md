## 本周发布更新

本周发布让 Agent 的工作过程更可见、更可控，丰富了技能交互，并提升了 SkillHub、模板、连接器、跨平台安装及 Web UI 的可靠性。

### 更新内容

- 会话可实时展示参与者的工作状态及 Agent 的思考和执行阶段，便于掌握任务进展。
- Codex 与 OpenClaw 现支持停止当前执行、流式响应及一致的推理强度设置，用户可更灵活地控制运行过程。
- 结构化技能输出支持资源链接、交互式问答、自动续接会话及脱敏问答历史，并增强了不同模型服务商下的兼容性。
- 远程 SkillHub 目录统一通过本地服务访问，并使用一致的 OpenCSG Hub 地址解析，提升技能浏览和获取的稳定性。
- Agent 模板布局和 Profile 界面更加统一，指令编辑与 Hub 模板详情也得到优化。
- 新增 GitLab PAT 连接器，并改善飞书绑定、管理员信息和会话保持，减少渠道使用中的状态异常。
- 优化附件操作、会话输入、时间标签和空状态等 Web UI 体验，同时加强运行时就绪检查、错误提示、Windows 支持及 `csgclaw-cli` 跨平台分发。

### 涉及版本

- `v0.4.2`: 新增参与者实时工作状态和结构化技能输出协议，完善 Agent 模板、GitLab 与飞书连接器、运行时可靠性及跨平台分发。
- `v0.4.3`: 新增 Agent 思考与工作阶段、停止控制和流式响应，增强技能交互与 SkillHub 访问，并优化附件、Profile、错误提示及 Web UI 稳定性。

## Weekly Release Update

This week’s releases make agent work more visible and controllable, enrich skill interactions, and improve the reliability of SkillHub, templates, connectors, cross-platform installation, and the Web UI.

### What's Changed

- Conversations now show participant working status and live agent thinking and execution stages, making task progress easier to follow.
- Codex and OpenClaw now support stopping active work, streamed responses, and consistent reasoning-effort controls for more flexible runtime control.
- Structured skill output now supports resource links, interactive questions, automatic session continuation, and redacted Q&A history, with stronger compatibility across model providers.
- The remote SkillHub catalog is now accessed through the local server with consistent OpenCSG Hub resolution for more reliable skill discovery and retrieval.
- Agent template layouts and profile experiences are more consistent, with improved instruction editing and Hub template details.
- GitLab PAT integration is now available, while Feishu binding, administrator data, and session preservation are more reliable.
- Attachment handling, conversation composition, time labels, and empty states have been refined, alongside stronger runtime readiness checks, error reporting, Windows support, and cross-platform `csgclaw-cli` distribution.

### Covered releases

- `v0.4.2`: Added real-time participant work status and the structured skill output protocol, and improved agent templates, GitLab and Feishu connectors, runtime reliability, and cross-platform distribution.
- `v0.4.3`: Added agent thinking and work stages, stop controls, and streamed responses; enhanced skill interactions and SkillHub access; and refined attachments, profiles, error reporting, and Web UI stability.
